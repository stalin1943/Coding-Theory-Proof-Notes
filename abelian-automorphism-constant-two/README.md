# The Exact Asymptotic Constant for Abelian Automorphism Groups over Finite Fields

Website: [Proof note](https://stalin1943.github.io/Coding-Theory-Proof-Notes/abelian-automorphism-constant-two/)

Hello from Yang Shifu, a long-time researcher and enthusiastic traveller in sequence coding, coding theory, and finite-field combinatorics.

This is the first public release, version 1.0. The PDF is a single-column proof note containing the complete argument, the coding-theoretic application, and the cited sources.

This note determines the exact asymptotic constant for the largest abelian automorphism groups of curves over every fixed finite field. It proves that the constant equals two, using a mean-conductor estimate, geometric class field theory, and a joint bound for class numbers and low-degree places. Carlitz cyclotomic function fields attain the bound asymptotically.
